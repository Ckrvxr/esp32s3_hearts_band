# MAX30100 模块研究报告

## 1. 概述

MAX30100 是 Maxim Integrated（现 Analog Devices）出品的一款集成式血氧饱和度（SpO₂）和心率监测传感器。它将**两个LED（红光 660nm + 红外光 880nm）**、**光电检测器**、**低噪声模拟信号处理**和**环境光消除**集成在一个 5.6mm×2.8mm×1.2mm 的 14-pin OESIP 封装中。

> **注意**：Maxim 已停产 MAX30100，替代型号为 MAX30101 / MAX30102（引脚兼容，功能增强）。

## 2. 硬件规格

| 参数 | 值 |
|---|---|
| 主电源 VDD | 1.7V~2.0V（典型 1.8V） |
| LED 电源 VLED+ | 3.1V~5.0V（典型 3.3V） |
| LED 电流 | 可编程 0mA~50mA（16 档） |
| 采样率 | 50Hz / 100Hz / 167Hz / 200Hz / 400Hz / 600Hz / 800Hz / 1000Hz |
| ADC 分辨率 | 13~16 bits（由脉冲宽度决定） |
| 接口 | I²C（最大 400kHz，地址 **0x57**） |
| 工作温度 | -40°C ~ +85°C |
| 关机电流 | 0.7µA（典型） |
| 内置温度传感器 | 片上温度传感，用于 SpO₂ 校准补偿 |

**引脚定义（14-pin OESIP）：**

| 引脚 | 名称 | 说明 |
|---|---|---|
| 1,7,8,14 | N.C. | 悬空，焊接至 PCB 焊盘用于机械稳定 |
| 2 | **SCL** | I²C 时钟 |
| 3 | **SDA** | I²C 数据（开漏双向） |
| 4 | PGND | LED 驱动器电源地 |
| 5 | IR_DRV | IR LED 阴极（接 LED 驱动器，浮空） |
| 6 | R_DRV | RED LED 阴极（接 LED 驱动器，浮空） |
| 9 | R_LED+ | 红光 LED 电源（阳极） |
| 10 | IR_LED+ | 红外 LED 电源（阳极） |
| 11 | VDD | 模拟电源输入（1.8V） |
| 12 | GND | 模拟地 |
| 13 | INT | 中断输出（开漏，低有效） |

> **模块版注意事项**：市面上大多数 MAX30100 模块已集成 3.3V LDO 稳压器和电平转换，可直接接 3.3V/5V MCU。但也有部分模块 I²C 上拉接的是 1.8V，需要移除板载上拉并外接至 MCU VCC 才能正常工作。

## 3. 通信协议：I²C

- **设备地址**：`0x57`（7-bit）
- **最大速率**：400kHz
- **基本操作**：
  - 写寄存器：发设备地址 + 寄存器地址 + 数据
  - 读寄存器：发设备地址 + 寄存器地址（重复起始条件）→ 发设备地址(读) → 读取数据
  - Burst 读 FIFO：可在一次传输中连续读取多个字节

## 4. 寄存器映射（核心）

| 地址 | 寄存器名 | 说明 |
|---|---|---|
| `0x00` | **INTERRUPT_STATUS** | 中断状态（PWR_RDY / SPO2_RDY / HR_RDY / TEMP_RDY / A_FULL） |
| `0x01` | **INTERRUPT_ENABLE** | 中断使能 |
| `0x02` | FIFO_WRITE_POINTER | FIFO 写指针 |
| `0x03` | FIFO_OVERFLOW_COUNTER | FIFO 溢出计数器 |
| `0x04` | FIFO_READ_POINTER | FIFO 读指针 |
| `0x05` | **FIFO_DATA** | FIFO 数据寄存器（burst 读取不自动递增） |
| `0x06` | **MODE_CONFIGURATION** | 模式配置（`0x02`=仅心率, `0x03`=SpO₂+心率, bit6=复位, bit7=关机） |
| `0x07` | **SPO2_CONFIGURATION** | SpO₂ 配置（bit6=高分辨率, bits[2-4]=采样率, bits[0-1]=脉冲宽度） |
| `0x09` | **LED_CONFIGURATION** | LED 电流（高4位=红光电流, 低4位=红外电流） |
| `0x16` | TEMPERATURE_DATA_INT | 温度整数部分 |
| `0x17` | TEMPERATURE_DATA_FRAC | 温度小数部分（LSB = 0.0625°C） |
| `0xFE` | REVISION_ID | 修订版本号 |
| `0xFF` | **PART_ID** | 器件 ID（应为 `0x11`） |

**FIFO 结构**：32 个采样点深度（`MAX30100_FIFO_DEPTH = 0x10`），每个采样点由 4 字节组成：

```
Byte 0: IR  高字节
Byte 1: IR  低字节
Byte 2: RED 高字节
Byte 3: RED 低字节
```

数据**左对齐**（即 16-bit ADC 结果放在高 16 位，低位补 0）。

## 5. 工作模式

```
MODE_CONFIGURATION 寄存器（0x06）:
  bit 7: SHDN  - 关机模式（1=关机）
  bit 6: RESET - 复位（自清零）
  bit 3: TEMP_EN - 启动温度采样
  bits 1-0: 工作模式
    0x02 = HR_ONLY（仅心率，仅 IR LED 工作）
    0x03 = SPO2_HR（心率+血氧，IR + RED 交替工作）
```

| 200µs | 13 bits | 1000Hz |

## 7. 驱动开发要点

### 7.1 初始化序列

```c
// 1. 初始化 I²C 总线（速率 ≥ 400kHz）
i2c_init(400000);

// 2. 验证器件 ID
part_id = read_reg(0xFF);
if (part_id != 0x11) error("Device not found");

// 3. 软件复位
write_reg(0x06, 0x40);  // 设置 RESET bit
delay(10);              // 等待复位完成

// 4. 配置模式
write_reg(0x06, 0x03);  // SpO₂+HR 模式

// 5. 配置采样率和脉冲宽度
write_reg(0x07, (1 << 2) | 0x03);  // 100Hz 采样率 + 1600µs 脉冲宽度（16-bit）

// 6. 配置 LED 电流
write_reg(0x09, (0x0F << 4) | 0x0F);  // 红光 50mA + 红外 50mA

// 7. (可选) 使能高分辨率模式
uint8_t spo2_cfg = read_reg(0x07);
write_reg(0x07, spo2_cfg | (1 << 6));

// 8. 重置 FIFO 指针
write_reg(0x02, 0);
write_reg(0x04, 0);
write_reg(0x03, 0);
```

### 7.2 数据读取流程

```c
// 1. 计算 FIFO 中可用数据数
uint8_t wr_ptr = read_reg(0x02);
uint8_t rd_ptr = read_reg(0x04);
uint8_t available = (wr_ptr - rd_ptr) & 0x0F;  // 取低4位（FIFO 深度 16）

// 2. Burst 读取 FIFO 数据
if (available > 0) {
    uint8_t buf[available * 4];
    burst_read(0x05, buf, available * 4);

    for (int i = 0; i < available; i++) {
        uint16_t ir  = (buf[i*4]   << 8) | buf[i*4+1];
        uint16_t red = (buf[i*4+2] << 8) | buf[i*4+3];
        // 处理 ir 和 red 值
    }
}
```

### 7.3 中断方式（可选）

MAX30100 提供 4 种中断：

- `A_FULL` (bit7): FIFO 几乎满
- `TEMP_RDY` (bit6): 温度采样就绪
- `HR_RDY` (bit5): 心率数据就绪
- `SPO2_RDY` (bit4): SpO₂ 数据就绪
- `PWR_RDY` (bit0): 上电复位完成

## 8. 信号处理流水线

MAX30100 只提供原始 ADC 数据，**心率计算和 SpO₂ 计算都需在 MCU 端完成**。

```
原始 IR/RED 数据 (ADC raw)
    │
    ▼
DC 去除器 (DCRemover)  →  提取交流分量（AC component）
    │                        └─ 即 PPG 波形
    ▼
低通滤波器 (LPF, ~6Hz Butterworth)  →  平滑去噪
    │
    ├→ 心率检测 (Beat Detector)
    │      └ 自适应阈值 + 状态机，计算 BPM
    │
    └→ SpO₂ 计算
           └ R = (AC_red / DC_red) / (AC_ir / DC_ir)
           └ SpO₂ = LUT(R) 或拟合公式
```

### DC 去除器

```c
// 一阶高通滤波器（指数滑动平均）
dcw = x + alpha * dcw;          // alpha ≈ 0.95
ac_value = dcw - prev_dcw;      // 输出交流分量
```

### 心率检测算法

基于**自适应阈值**的状态机：

1. **INIT** → 2 秒初始化静默期
2. **WAITING** → 等待信号超过阈值
3. **FOLLOWING_SLOPE** → 跟踪下降沿
4. **MAYBE_DETECTED** → 检测到候选心跳
5. **MASKING** → 200ms 消隐窗口（防止重复触发）

阈值自适应跟随：检测到心跳后阈值设为峰值的 30%，无心跳时按 0.99 衰减。

### SpO₂ 计算公式

血氧饱和度由**红光吸收比**和**红外光吸收比**的比值 R 决定：

```
R = (AC_red / DC_red) / (AC_ir / DC_ir)
```

通过查找表（LUT）将 R 值映射为 SpO₂ 百分比。该库内部使用 43 个点的经验查找表。

## 9. 各平台适配示例

### ESP-IDF (ESP32)

```c
#include "driver/i2c.h"

#define MAX30100_ADDR       0x57
#define I2C_MASTER_NUM      I2C_NUM_0

esp_err_t max30100_read_reg(uint8_t reg_addr, uint8_t *data) {
    i2c_cmd_handle_t cmd = i2c_cmd_link_create();
    i2c_master_start(cmd);
    i2c_master_write_byte(cmd, (MAX30100_ADDR << 1) | I2C_MASTER_WRITE, true);
    i2c_master_write_byte(cmd, reg_addr, true);
    i2c_master_start(cmd);
    i2c_master_write_byte(cmd, (MAX30100_ADDR << 1) | I2C_MASTER_READ, true);
    i2c_master_read_byte(cmd, data, I2C_MASTER_NACK);
    i2c_master_stop(cmd);
    return i2c_master_cmd_begin(I2C_MASTER_NUM, cmd, 1000 / portTICK_PERIOD_MS);
}
```

### STM32 (HAL)

```c
#define MAX30100_ADDR       (0x57 << 1)  // HAL 使用 8-bit 地址

HAL_StatusTypeDef max30100_read(uint8_t reg, uint8_t *data) {
    return HAL_I2C_Mem_Read(&hi2c1, MAX30100_ADDR, reg,
                            I2C_MEMADD_SIZE_8BIT, data, 1, 100);
}
```

### Linux (Raspberry Pi / 嵌入式 Linux)

```c
#include <linux/i2c-dev.h>
#include <fcntl.h>
#include <sys/ioctl.h>

int file = open("/dev/i2c-1", O_RDWR);
ioctl(file, I2C_SLAVE, 0x57);

// 读寄存器
uint8_t reg = 0x07;
uint8_t val;
write(file, &reg, 1);
read(file, &val, 1);

// Burst 读 FIFO
uint8_t reg = 0x05;
uint8_t buf[64];
write(file, &reg, 1);
read(file, buf, 64);
```

### Zephyr RTOS

```c
#include <zephyr/drivers/i2c.h>

#define MAX30100_ADDR  0x57

uint8_t max30100_read_reg(uint8_t reg) {
    uint8_t val;
    i2c_write_read(&i2c_dev, MAX30100_ADDR, &reg, 1, &val, 1);
    return val;
}
```

## 10. 重要注意事项

| 问题 | 说明 |
|---|---|
| **I²C 上拉电阻** | 必须使用 4.7kΩ 或更小的上拉电阻，否则 400kHz 通信不可靠 |
| **电平兼容性** | MAX30100 I²C 引脚耐压不限 VDD，SCL/SDA 可上拉至 3.3V 或 5V |
| **模块差异** | 不同模块的板载 LDO/电平转换电路不同，部分模块需移除原上拉 |
| **LED 电流调节** | IR LED 电流对信号质量至关重要，建议手指按压时调节到信号适中（不饱和） |
| **运动伪影** | MAX30100 无硬件运动伪影消除，需靠软件算法或机械固定（如手指夹） |
| **温漂补偿** | 片上温度传感器可用于补偿 RED LED 波长随温度的漂移（高级功能） |
| **MAX30102 区别** | MAX30102 是 MAX30100 的改进版，封装兼容，但 I²C 地址不同（`0x57` → `0xAE`/`0x57` 取决于配置） |
