# AGC 自动增益控制 — 改进算法

## 1. 双环解耦架构

```
主环 (IR 跟踪)       副环 (RED 平衡)
周期 500ms           周期 1000ms
     │                     │
     ▼                     ▼
IR 中位数判决         DC 比值判决
     │                     │
     ▼                     ▼
非线性比例步进        ±1 微调步进
     │                     │
     └─────────┬───────────┘
               ▼
       写入 LED_CONFIG
```

主环负责将 IR 通道 ADC 基线锁定在目标区间。副环在 IR 稳定的基础上，独立微调 RED 电流使双通道直流基线匹配，避免肤色/佩戴差异导致 RED 通道饱和或 SNR 不足。

---

## 2. 主环 — IR 电流控制

### 2.1 输入变量

| 符号 | 含义 | 来源 |
|---|---|---|
| \(x_{IR}[n]\) | IR 通道原始 ADC 值 | MAX30100 FIFO |
| \(u_{IR}\) | IR 电流寄存器值 (0~15) | 内部状态 |
| \(T_{AGC}\) | 控制周期 500ms | 定时器 |

### 2.2 信号预处理

每周期收集最近 8 个 IR 样本，取中位数作为判决依据：

\[
\hat{x}_{IR} = \text{median}\{x_{IR}[n], x_{IR}[n-1], \dots, x_{IR}[n-7]\}
\]

计算误差：

\[
e = \hat{x}_{IR} - 35000
\]

### 2.3 死区判决

\[
\Delta u_{IR} = \begin{cases}
+2, & e < -15000 \\
+1, & -15000 \leq e < -10000 \\
0,  & |e| \leq 10000 \\
-1, & 10000 < e \leq 15000 \\
-2, & e > 15000
\end{cases}
\]

### 2.4 输出限幅

\[
u_{IR}[k] = \max(0, \min(15,\; u_{IR}[k-1] + \Delta u_{IR}))
\]

### 2.5 特殊处理

**饱和保护：**
\[
\hat{x}_{IR} \geq 65500 \implies \Delta u_{IR} = -3
\]

**无信号跳过：**
\[
\hat{x}_{IR} < 100 \implies \text{跳过本轮调整}
\]

**启动初始值：**
\[
u_{IR}[0] = 8 \quad (\approx 27\text{mA})
\]

## 3. 副环 — RED 电流平衡

### 3.1 输入变量

| 符号 | 含义 | 来源 |
|---|---|---|
| \(dcw_{IR}\) | IR 通道直流基线 | DCRemover 内部状态 |
| \(dcw_{RED}\) | RED 通道直流基线 | DCRemover 内部状态 |
| \(u_{RED}\) | RED 电流寄存器值 (0~15) | 内部状态 |
| \(T_{BAL}\) | 平衡周期 1000ms | 定时器 |

### 3.2 DC 比值计算

\[
r_{DC} = \frac{dcw_{RED}}{dcw_{IR}}
\]

### 3.3 判决

\[
\Delta u_{RED} = \begin{cases}
+1, & r_{DC} < 0.8 \\
0,  & 0.8 \leq r_{DC} \leq 1.2 \\
-1, & r_{DC} > 1.2
\end{cases}
\]

### 3.4 输出限幅

\[
u_{RED}[k] = \max(0, \min(15,\; u_{RED}[k-1] + \Delta u_{RED}))
\]

## 4. 完整控制流程

```
[定时器] T = 500ms 触发
  │
  ├─→ 读取 FIFO，提取最近 8 个 IR 样本
  │
  ├─→ 计算中位数 x̂
  │     │
  │     ├─ x̂ < 100 → 跳过（无手指）
  │     │
  │     ├─ x̂ ≥ 65500 → uIR = max(uIR - 3, 0)，直接写入
  │     │
  │     └─ 正常：
  │           e = x̂ - 35000
  │           if (e < -15000)       uIR += 2
  │           else if (e < -10000)  uIR += 1
  │           else if (|e| ≤ 10000) → 死区，不操作
  │           else if (e ≤ 15000)   uIR -= 1
  │           else                  uIR -= 2
  │           uIR = clamp(uIR, 0, 15)
  │
  ├─→ 写入 LED_CONFIG = (uIR << 4) | uRED
  │
  └─→ [定时器] T 是否同时是 1000ms 的整数倍？
        │
        ├─ 否 → 结束
        │
        └─ 是 → 读取 DCRemover 的 dcw_IR, dcw_RED
                  r = dcw_RED / dcw_IR
                  if (r < 0.8)            uRED++
                  else if (0.8 ≤ r ≤ 1.2) → 不动
                  else                     uRED--
                  uRED = clamp(uRED, 0, 15)
                  写入 LED_CONFIG = (uIR << 4) | uRED
```

## 5. 参数汇总

| 参数 | 值 | 说明 |
|---|---|---|
| 主环周期 | 500 ms | IR 电流调整间隔 |
| 副环周期 | 1000 ms | RED 平衡调整间隔 |
| 中位数窗口 | 8 样本 | 80ms 时间窗口 |
| 目标中值 | 35000 | ADC 目标基点 |
| 死区 | [25000, 45000] | 不触发调整 |
| 大步阈值 | ±15000 | 切换大步/小步 |
| 饱和阈值 | 65500 | ADC 饱和保护 |
| 无信号阈值 | 100 | 跳过 AGC |
| 启动电流 | 8 (27mA) | 首次初始值 |
| RED 比率目标 | 0.8~1.2 | DC 基线匹配 |

## 6. 寄存器写入

LED_CONFIG 寄存器 `0x09` 格式：

```
Bit 15~8:  保留
Bit 7~4:   IR_PA (IR 电流)
Bit 3~0:   RED_PA (RED 电流)
```

写入操作：

```
uint8_t led_cfg = (uIR << 4) | uRED;
MAX30100_WriteReg(0x09, led_cfg);
```

IR 与 RED 电流等级与物理电流的对应关系见 MAX30100 数据手册 Table 6。
